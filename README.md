# adelsaiq/.github

> Organization-wide community health files for the
> [adelsaiq](https://github.com/adelsaiq) organization.

The default `SECURITY.md`, `SUPPORT.md`, and `CODE_OF_CONDUCT.md` here apply to
every AdelsaIQ repository lacking its own.

There is deliberately **no `profile/README.md`**. The organization has no public
repositories, so a profile page would describe work nobody can open. Add one when
that changes — see the tier model in the standard that governs these surfaces.

Disclosure goes to `security@adelsaiq.ai`, support to `support@adelsaiq.com`.
